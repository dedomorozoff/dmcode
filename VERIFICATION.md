# VERIFICATION.md — чек-лист живых прогонов

> Цель: превратить «проверено только тестами» в «проверено на живой сессии».
> Каждый пункт — это то, что unit-тесты уже сторожат, но ни разу не было
> проверено против настоящего endpoint'а и настоящего терминала.
>
> Правила прогона:
> - живой endpoint (любой chat-wire: OpenRouter, Groq, llama-server с
>   tool-calling) и настоящий терминал, не тестовый хarness;
> - перед прогоном — свежий бинарь из `make build`, и убедиться, что
>   запускаешь именно его (см. AGENTS.md §4 «Diagnosing "the TUI shows X
>   but my test says otherwise"» — сначала исключить старый процесс);
> - провал = задокументировать точные шаги и вывод, завести фикс с тестом,
>   и только потом ставить галочку;
> - успех = галочка здесь **и** вычёркивание соответствующего пункта из
>   предупреждения в начале AGENTS.md.

## 1. Откат режет память модели, а не только экран

- [ ] Прогнать ход, где агент сделал явное действие: `write_file` с
      содержимым, которое он потом запомнит («запиши в /tmp-note.txt слово
      BANANA»).
- [ ] До отката спросить: «Какое слово ты записал?» — отвечает BANANA.
- [ ] `ctrl+z` (ход отменён, промпт вернулся в поле ввода).
- [ ] Снова спросить: «Какое слово ты записал?» — **не должен знать**:
      события хода вырезаны из `RewindToLastUserMessage`.
- Провал выглядит так: второй вопрос отвечает BANANA → `RewindToLastUserMessage`
  порезал транскрипт, но раннер читает store мимо среза.

## 2. Round-trip: сессия после перезапуска = живой ход

- [ ] Сессия с тул-ходцами (grep, write_file, диф-блок) — закрыть dmcode.
- [ ] `dmcode -s` — транскрипт восстановился **включая** строки инструментов
      и блоки изменений (не только прозу).
- [ ] Задать продолжение, зависящее от контекста («измени ту строку в том
      файле ещё раз») — агент понимает, о чём речь, т.е. восстановленные
      события годятся для живого хода, а не только для показа.
- Провал: инструменты пропали из ленты → `Turn.Entries`/`eventText` расходятся
  с тем, что пишет JSONL; агент не понимает продолжение → события прочитались,
  но не тем порядком/видом.

## 3. `ask_user` против живого хода

- [ ] Промпт, где агент обязан спросить («прежде чем менять схему БД —
      спроси меня, какой движок»).
- [ ] Оверлей вопроса появляется **под** транскриптом, ответ на вариант
      уходит модели, ход продолжается в том же ходе.
- [ ] `DMCODE_ASK_TIMEOUT=10`: не отвечать 10 с → выбран рекомендованный
      вариант, модель получила пометку о дефолте, зависания нет.
- [ ] Мультивыбор и свой вариант работают на живом вводе.
- Провал: ход завис после ответа → канал reply не буферизован или broker
  разминулся с tool-горярутиной.

## 4. `switch_mode` plan→act не подвешивает раннер

- [ ] План-режим, промпт «спланируй и попроси переход к правке».
- [ ] Агент зовёт `switch_mode`, ход корректно завершается (`EndInvocation`),
      бейдж сменился **между** ходами, не в середине.
- [ ] Следующий ход: инструменты act доступны, предыдущий контекст плана
      сохранён (спросить «что мы запланировали?»).
- [ ] `Tab` из act возвращает план; в act `switch_mode` недоступен агенту.

## 5. Субагент: делегирование и размер отчёта

- [ ] Act-режим, промпт с явным делегированием («используй sub_agent, чтобы
      выяснить, где обрабатывается X»).
- [ ] Вложенный ход отработал, отчёт в родительской ленте, родитель ответил
      по делу.
- [ ] Вызвать отчёт заведомо больше окна: «попроси субагента вернуть весь
      файл без сокращений» — родитель не должен лопнуть или затупить;
      отчёт обрезан с явным признаком.
- [ ] В `/sessions` сессия субагента **не** появляется; в памяти родителя
      её чтение не осело лишним.

## 6. Картинка до живого vision-endpoint

- [ ] Chat-wire endpoint с вижилном (например OpenRouter gemini-class).
- [ ] Прикрепить скриншот (`ctrl+v`), отправить, спросить про картинку —
      модель отвечает **по содержанию**, не «я не вижу изображения».
- [ ] `/image <путь>` с jpg/png-файлом — то же самое.
- [ ] Большой файл (~3 МБ PNG) — не убивает ход (редукция до 1568px/4 МБ).
- [ ] На `/v1/responses` attach **отказывается сразу** с указанием
      `DMCODE_API=chat` — это ожидаемое поведение, проверить что отказ есть.
- Это самый главный неизвестный всей фичи: до сих пор ни одна картинка не
  доходила до живого endpoint'а.

## 7. Клик по цитате в живом терминале

- [ ] Промпт: «ответь одной строкой вида internal/ui/ui.go:1 с описанием».
- [ ] Цитата размечена (цвет/вес), клик открывает редактор на строке 1.
- [ ] Цитата в **средней** строке длинного ответа (после скролла) — координаты
      не съехали (`transcriptTop` + `vp.YOffset()` на живом фрейме).
- [ ] Клик по домену вида `example.com:8080` ничего не открывает.
- [ ] `alt+g` из редактора возвращает чат-курсор к последней цитате.

## 8. `/compact` в живом TUI-ходе

- [ ] Нарать длинный контекст (несколько тул-ходов), `/compact`.
- [ ] Сайдбар CONTEXT показал сводку; следующий ход опирается на **содержание**
      older turns (спросить факт из дальнего начала — помнит по сводке).
- [ ] `esc` во время суммаризации отменяет без зависания.
- [ ] `/compact` на свежей сессии = «nothing to compact yet», не ошибка.

## 9. Yolo-ход целиком

- [ ] `shift+tab` → бейдж yolo; промпт с заведомым выбором (agent обычно
      спросил бы) — действует сам, `ask_user` не зовёт.
- [ ] `shift+tab` снова → вернулся **тот же** режим, что был до yolo
      (plan → yolo → plan, не plan → yolo → act).
- [ ] `/mode yolo` и агентский request в yolo отказаны (пользовательское
      решение, только клавиша).

## 10. `read_file` paging: модель учитывает новую нумерацию

- [ ] Промпт: «найди в README.md, на какой строке раздел про установку» —
      агент читает постранично через `offset_line`/`next_offset` и называет
      номер строки **без** моей подсказки про нумерацию.
- [ ] Клик по названной цитате попадает в верное место (связка с пунктом 7:
      если строка офф-by-one — paging-контракт живой моделью не усвоен).

## 11. Файловый откат после реального tool-хода

- [ ] Промпт с `write_file`/`move_file`/`delete_file` (создал, переместил,
      удалил).
- [ ] `ctrl+z` — файлы ровно на исходных местах, CHANGES-панель не показывает
      правки, которых откат отменил.
- [ ] Ход с `run_command`-записью (`echo >> file`) — откат сообщает «not
      restored» про этот путь и **не** портит его половинчатым восстановлением.

## 12. Картинки/GIF в настоящем терминале

- [ ] Анимированный GIF во вкладке редактора: играет, скорость из файла,
      частичные кадры не пустые (композит).
- [ ] Узкое окно / ресайз: превью не прыгает, подпись на последней строке.
- [ ] Закрыть вкладку во время проигрывания — тишина, `imgPending` погас,
      вторая цепочка тиков не завелась.
- [ ] Выход из dmcode при играющем GIF — процесс выходит (цепочка тиков не
